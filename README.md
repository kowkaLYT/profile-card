# Profile Card

A modern personal profile card built with React, Vite and Tailwind CSS.

I wanted to make something simple but still interesting, so I added interactive tabs, responsive design and a custom animated background.

<img width="505" height="596" alt="image" src="https://github.com/user-attachments/assets/9749700f-5b8d-4bbf-aca1-aafeda46f50c" />

## ✨ Features

- About, Experience and Contact tabs
- Responsive design for desktop and mobile
- Social media links
- Email contact button
- Custom animated SVG background
- Smooth transitions and hover effects

## 🛠️ Technologies

- React
- JavaScript
- Vite
- Tailwind CSS
- React Icons
- SVG
